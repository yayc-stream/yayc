# **Yet Another YouTube Client**

{: .text-white}
YAYC 是一款适用于 Linux、Windows 和 macOS 的免费桌面 YouTube 客户端，基于 Qt6/QML 和 QtWebEngine 构建。
它提供书签、观看进度跟踪、视频队列和播放列表管理等功能，
让你无需打开大量浏览器标签页或窗口来跟踪多个视频和频道。
