# **Yet Another YouTube Client**

{: .text-white}
YAYC es un cliente de YouTube de escritorio gratuito para Linux, Windows y macOS, construido con Qt6/QML y QtWebEngine.
Ofrece marcadores, seguimiento del progreso de visualización, gestión de colas de vídeos y listas de reproducción, y más,
evitándote tener que mantener abiertas muchas pestañas o ventanas del navegador para seguir varios vídeos y canales.
